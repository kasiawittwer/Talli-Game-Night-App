# Custom fonts

Add these font files here so the app can load them:

1. **Aquavit** (headers, logo, alphabet dice)
   - Get it from [Google Fonts – Aquavit](https://fonts.google.com/specimen/Aquavit).
   - Download the family, then add the Regular (`.ttf`) file.
   - **Rename or place it as:** `Aquavit-Regular.ttf`

2. **Wix Madefor Text** (body text)
   - Get it from [Google Fonts – Wix Madefor Text](https://fonts.google.com/specimen/Wix+Madefor+Text).
   - Download the family, then add the Regular (`.ttf`) file.
   - **Rename or place it as:** `WixMadeforText-Regular.ttf`

After adding both files, restart the app (`npx expo start`). The root layout loads them on launch and keeps the splash screen visible until they’re ready.
